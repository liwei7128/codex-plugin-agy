## 1. Test Methodology & Isolation Controls

Following earlier standalone MCP client testing, this run executed **genuine authenticated Antigravity host-mediated turns** using `agy 1.5.18` (`--model gemini-4-neon-xhigh --output-format stream-json`):

- **Zero global configuration mutations**: The verbatim packaged `dist/plugin/` bundle (zero `node_modules`) was mounted as a workspace-scoped plugin at `<temp-git-repo>/.agents/plugins/codex-plugin-agy/` (with `.agents/` excluded via `.git/info/exclude` so Git working trees stayed clean). Global `agy plugin list --json` remained `[]` before and after all tests.
- **Host-enforced non-takeover boundary**: Every `agy` run used a session-only `--settings` allowlist granting **only** the 10 MCP tools on `codex-plugin-agy_codex` (`mcp(codex-plugin-agy_codex/codex_*)`). Antigravity therefore blocked direct file edits and shell execution by Neon during implementation scenarios, guaranteeing that **GPT-6.2 Sol** performed all delegated code edits and tests.
- **Independent verification**: After each delegated write scenario (`Scenarios 4–6`, `Scenario 7`, `Scenario 10`), Neon independently inspected `git status`, `git diff`, `node --test`, `broker.json`, and `review-gate-state.json` outside the `agy` session.
- **Cleanup**: Both disposable Git repositories and their temporary plugin state subdirectories were removed after capturing evidence; zero leaked broker records remained.

## 4. Notable Live Host Observations

1. **Workspace-scoped `.agents/plugins/codex-plugin-agy/` works natively on both `agy 1.5.18` CLI and `Antigravity 2.35.2` LS** inside initialized Git repositories (while `agy plugin list` reports only globally installed plugins under `~/.gemini/config/plugins/`).
2. **Eager vs. Lazy MCP routing works as designed**: `agy 1.5.18` injected `codex_delegate`, `codex_status`, and `codex_result` directly as first-class eager declarations (`mcp_codex-plugin-agy_codex_*`) and exposed the remaining 7 tools lazily via `call_mcp_tool` with cached JSON schemas under `~/.gemini/antigravity-cli/mcp/codex-plugin-agy_codex/`.
3. **Host schema enforcement complements plugin Zod validation**: When Neon called eager `mcp_codex-plugin-agy_codex_codex_delegate` with `sandbox: "danger-full-access"`, Antigravity itself rejected the call client-side (`value must be one of 'read-only', 'workspace-write'`), and calling the same payload via `call_mcp_tool` verified the server-side `INVALID_ARGUMENTS` envelope independently.
4. **Live host Review Gate `executionNum` behavior across resumed conversations**: Resuming the same conversation via `agy --conversation <id>` sent `executionNum: 0` on Turn 2 while continuing within a single turn sends `executionNum: 1` (observed in Phase 0.5). The `REV-05` fix (`execution <= 0 || execution > previous.execution` on new `lastUserInput` hash) handles both host behaviors accurately.
