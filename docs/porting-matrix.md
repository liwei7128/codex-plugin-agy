# Upstream Porting & Feature Parity Matrix

> **Note**: This document serves as the authoritative porting matrix for `codex-plugin-agy` (fulfilling both the Phase 0 `docs/porting-matrix.md` deliverable and `SPEC.md` Section 3's porting matrix requirement). Upstream baseline: `openai/codex-plugin-cc` tag `v1.0.6` (commit `db52e28f4d9ded852ab3942cea316258ae4ef346`).

Current host baseline and confirmed integration deltas are recorded in [Phase 0.5](host-compatibility-delta.md).

---

## 1. Classification Definitions

Every upstream file and feature is classified into exactly one of the five `SPEC.md` categories:

| Category | Definition |
| --- | --- |
| **Reused** | Vendored directly from `openai/codex-plugin-cc` into `src/upstream/` (or `prompts/` / `schemas/`) with zero or trivial path/branding edits, keeping upstream sync diffs minimal. |
| **Adapted** | Upstream design and substantial logic retained, modified to remove Claude Code coupling, fix audited reliability/security defects (`AUD-01`..`AUD-12`), or support Codex `0.172.0` protocol extensions. |
| **Reimplemented** | Built fresh in TypeScript/ESM because the host integration model (Antigravity Native Plugin + MCP Server + Orchestration + Worktree Isolation) has no reusable upstream equivalent. |
| **Unsupported** | Deliberately not ported because the upstream feature relies on Claude Code-exclusive private mechanics or unsupported external formats; explicit reason documented below. |
| **Deferred** | Out of scope for Phases 1–4 MVP/production release; tracked for a future iteration with concrete rationale. |

## 5. Upstream Synchronization Strategy

To allow low-friction merges when OpenAI updates `openai/codex-plugin-cc`:

1. **Isolated Vendored Directory (`src/upstream/`)**:
   - Files marked **Reused** or minimally **Adapted** (`args.mjs`, `fs.mjs`, `prompts.mjs`, `workspace.mjs`, `git.mjs`) live verbatim or with clearly commented `// [codex-plugin-agy]` patch markers under `src/upstream/`, and host-agnostic assets live under `prompts/` and `schemas/`.
   - All Antigravity-specific logic (`src/adapters/antigravity/`, `src/mcp/`, `src/config/`, `src/security/`, `src/workspace/`, `src/diagnostics/`, `src/formatting/`) lives in separate TypeScript modules that import *from* `src/upstream/` — never the reverse.
2. **Protocol Regeneration Workflow**:
   - Run `npm run generate:protocol` (`codex app-server generate-ts --out .generated/app-server-types`) + `npm run typecheck` whenever upgrading `@openai/codex` to detect upstream App Server breaking changes at compile time.
3. **Sync Checklist (documented in `UPSTREAM.md`)**:
   - Record current base SHA (`db52e28f4d9ded852ab3942cea316258ae4ef346`).
   - Run `git log <old-sha>..origin/main -- plugins/codex/` in a scratch clone of `openai/codex-plugin-cc`.
   - Cherry-pick/port changes in `lib/git.mjs`, `lib/codex.mjs`, `lib/app-server.mjs`, `prompts/`, and `schemas/` while preserving `AUD-01`..`AUD-12` hardening invariants and running the full automated test suite.
