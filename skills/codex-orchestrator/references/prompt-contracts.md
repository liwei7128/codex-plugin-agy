# Worker prompt contracts

Use the blocks that the task needs. List concrete files, decisions, and acceptance criteria. Keep the user's permissions and billing choices.

```xml
<task>Describe the authorized implementation objective and its file scope.</task>
<verification_loop>Name the checks to run and the evidence to return.</verification_loop>
<grounding_rules>Distinguish observed results, inferred conclusions, and open issues.</grounding_rules>
<action_safety>Preserve user changes and stop at approval boundaries.</action_safety>
```

Adapted from model-independent prompt recipes in the pinned upstream baseline. See UPSTREAM.md.
